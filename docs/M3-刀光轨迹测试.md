# M3 刀光轨迹测试记录

日期：2026-11-19 · 分支 main · 目标：刀刃轨迹 渐隐尾巴 + 帧间插值，60fps 下平滑。

## 交付物

- `game/trail.py`：`BladeTrail` —— 每只手一条轨迹。
  - `push(x, y, t)`：视觉采样点（拒绝乱序时间戳）；
  - `tip(now)`：末两采样线性速度**外推**虚拟刀尖（cap 1.5 个采样周期，手停不飞出）；
  - `draw(p, now)`：过期点（>0.25s，同参考项目 KNIFE_TRAIL_LIFETIME）剪除，逐段两级描边（宽辉光 70α + 亮核心 235α），透明度/宽度按新旧渐变，末段连到虚拟刀尖；
  - 零长段（<0.5px，采样噪声）跳过。
- `vision/shared.py`：snapshot 增返 `pub_t`（最近一次发布的采样时刻，渲染线程据此判"新采样"）。
- `game/window.py`：`_feed_trails` —— 真机模式按 pub_t 变化推入 blades[0/1] 对应轨迹（缺席的手自然渐隐）；合成模式（合成视觉看不见人）改为脚本化双手正弦扫掠 @30Hz，走完整 M3 渲染路径。
- `main.py`：selftest 增判 `trail_points >= 3`。

## 自测（PASS ×2）

离屏（合成）：

```
SELFTEST seconds=12.0 ticks=749 paints=750
SELFTEST avg tick fps=62.4 avg paint fps=62.5
SELFTEST vision status=ok hz=30 samples=324 infer_ms=10.0
SELFTEST trail_points=5
SELFTEST PASS (require render>=55fps, vision>=20Hz, trail>=3pts)
```

真屏 `--selftest 6 --visible`（垂直同步）：

```
SELFTEST seconds=6.1 ticks=375 paints=375
SELFTEST avg tick fps=61.0 avg paint fps=61.0
SELFTEST vision status=ok hz=30 samples=144 infer_ms=9.4
SELFTEST trail_points=6
SELFTEST PASS
```

结论：双刀光 + 双级描边在 60fps 预算内零掉帧（62.5 离屏 / 61.0 真屏）；30Hz 采样 + 外推刀尖下轨迹连续；0.25s 尾巴点数稳定（5~6）。

## 设计取舍

- **外推而非回溯插值**：回溯插值需缓存一帧延迟；外推零延迟、手感即时，代价是手急停时最多超前 1.5 个采样周期（~50ms），视觉上无感。
- **段级双层描边** vs 参考项目逐像素画圆 mask：QPainter 两遍 drawLine 在本机 8 段×2 手×2 遍=32 次/帧，实测无帧率影响，且天然支持抗锯齿。
- **手-轨迹按索引绑定**（blades[0]→左、blades[1]→右）：MediaPipe 双 pose 输出顺序稳定；遮挡导致单手消失时对应轨迹自动渐隐，不串手。

## 遗留

- 真机视觉效果（真人手速下的辉光观感）待摄像头恢复后 `python main.py --camera 0` 人工确认；参数（寿命 0.25s / 宽度 2..11px）留 M5 打磨窗口。
