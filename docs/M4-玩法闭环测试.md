# M4 玩法闭环 · 测试记录

日期：2026-11-19 · 对应计划书 M4（玩法闭环：水果、计分、炸弹、状态机）

## 新增模块

- `game/fruits.py` — 纯数据与物理，无 Qt 依赖：
  - `GAME_W, GAME_H = 1280, 720`；`GRAVITY = 1800 px/s²`（dt 制，帧率无关）
  - 水果表（分值 / 半径 / 初速，自绘配色）：橙 2 分 r34 1500、猕猴桃 2 分 r30 1500、菠萝 3 分 r42 1000、西瓜 4 分 r50 1000；炸弹 r36 875 px/s、深灰底 + 红色闪烁引信
  - `Fruit` / `HalfFruit`（半片，刀向垂直 kick 260 + 上抛 -120，寿命 1.2s）/ `Particle`（果汁，0.35g，0.45s）/ `FloatText`（飘字 0.9s）
  - `segment_hits_circle()`：点到线段距离 ≤ 半径（含退化段处理）——与计划书一致的碰撞判据
  - `spawn_object(round)`：第 3 回合起 1/8 概率炸弹；底部 x∈[0.32,0.68]W、仰角 78~102°、初速 ×U(1.0,1.5)
- `game/state.py` — 状态机：
  - 回合制：每轮 2~5 个、波内错峰 0.12~0.4s；`ROUND_COOLDOWN 2s`
  - 漏接扣 2 倍分值（`MISS_PENALTY=2`）+ 红色飘字；漏炸弹不扣分（躲开也算赢）
  - 切炸弹 → GAME OVER 覆盖层，`GAME_OVER_RESTART 4s` 后自动重开（selftest 期间游戏持续自我运动）
  - `Stats` 跨重开累计 spawned/sliced/missed/bombs_sliced/rounds_played，供自测断言
  - `collision_selfcheck()`：4 组点到线段断言（近距/端点区/远距/退化段），随 selftest 跑
- `game/window.py` — 集成：`_tick` 里 `state.update(dt)` + 收集 `collision_segments` → `collide_blade`；paint 增画水果（径向渐变）、半片（drawPie 180° 随速度旋转）、果汁粒、飘字、GAME OVER 覆盖层；HUD 第 4 行 `state.hud()`；demo 刀 2 改为穿过水果必经带的走廊轨道

## 首测崩溃与修复

**NameError 每帧刷屏**：`game/state.py` 掉果分支用了 `GAME_H`，但 import 漏了这个名字：

```
File "game\state.py", line 98, in update
NameError: name 'GAME_H' is not defined
```

连锁症状复用了 M2 的教训（PySide6 槽函数异常不打死事件循环）：_tick 每帧抛异常、paint 冻结在 218/1249、missed 被反复重计到 1032、score -8252。
修复：import 行补 `GAME_H`。一行修复后 paints 恢复 1250/1249。

**第二处修正**：`stats.rounds_played` 原实现是 `= self.round`（镜像当前回合号，重开即归零），与"跨重开累计"的设计意图不符 → 改为 `+= 1`。

## 补充：合成自测的"刀刃"改为自动追果（防止随机 FAIL）

早期合成自测用固定正弦扫掠驱动刀刃，命中与否取决于水果随机落点：10 秒跑出现过 `sliced=0 missed=9` 的失败（判定条件要求 `sliced>=1`）。现改为 `_push_demo_blades()`：两只脚本手**优先追最靠下的水果**（`f.value > 0`，永不追炸弹），以 `DEMO_BLADE_SPEED = 4200 px/s` 限速逼近，没有水果时回落到原来的扫掠。

连续三次 10 秒合成自测：`spawned=7/12/12 sliced=6/12/11 missed=0/0/0`，全部 PASS。命中从"碰运气"变成"必然发生"，回归测试才真正守住 `trail → collision → slice` 这条链路。
